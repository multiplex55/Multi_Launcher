## Discovery completion checklist

Inspect window creation, tool/Panel dispatch, visibility, viewport use, settings and widget factories, custom drawing, command routes, plugin registries, context menus, confirmations, capture/native surfaces and configuration gates. Walk actual reachable routes with controlled fixtures.

For each candidate expand the child surfaces, supported dock/pop/independent/modal/floating/overlay modes, meaningful states, controls, input, data ownership and cross-feature handoffs. Include hidden/advanced controls and optional features available at the baseline; external service unavailability does not erase their UI obligation.

Record every unidentified or uncertain surface and resolve ownership. Feature-specific settings belong to the feature’s goal; G06 owns their common host/registry. Common controls can be shared implementations but each use retains the relevant behavior criteria.

Inventory is complete only when source registrations and real reachable routes reconcile, no required child/mode/optional surface is orphaned, and the reviewer can trace the denominator. Do not infer completion from the size of this seed table.
