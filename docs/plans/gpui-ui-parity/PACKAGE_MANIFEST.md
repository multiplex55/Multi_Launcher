# Package manifest and use

This is a preparation artifact for the user to supply to an implementation AI. It is not an existing repository checkout or a record of completed migration work.

The `docs/` tree is laid out for placement into Multi_Launcher. The master Goal and Kickstart are at docs root. Linked contracts, tracker initialization and individual work packets are under docs/plans/gpui-ui-parity.

The package contains no application code changes, vendored dependencies, credentials or user data. Source facts are linked to the inspected planning commit. At kickoff refresh latest master and reconcile the execution baseline before implementing.

The ZIP is a delivery convenience; the Markdown files remain the complete readable contract. Do not treat an archive copy and extracted documents as competing execution ledgers. Keep one authoritative copy in the migration branch once started.
