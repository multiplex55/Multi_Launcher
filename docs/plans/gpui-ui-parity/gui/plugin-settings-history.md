# History Plugin Settings

G05 owns `plugin-settings-history` in the common Settings host. Feature effects stay with the existing runtime owner.

| Criterion | Source-backed behavior |
| --- | --- |
| HISTORY-SETTINGS-01 | Preserve the 10–500 history limit, default 100, and current observed Settings control. Common Save updates the committed history limit used when recording future executions. Keep the provider's existing bounded display behavior. |

Select `settings_search_cross_owner_builtin_provider_focuses_its_actual_response` and `settings_search_delivery_reveals_disabled_builtin_enable_without_calling_provider`. Use a scratch history file.
