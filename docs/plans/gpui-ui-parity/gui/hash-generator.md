# Hash Generator

G04 owns `hash-generator`. Native egui evidence covers the keyboard route, independent popout, Text calculation, comparison edits, all algorithm options, SHA-1 warnings, Unicode multiline comparison, picker dismissal and empty-path validation. Partial GPUI evidence covers Text, Clipboard and File calculation, both picker owners, and retained docking. `G03-C2B-CLEAN-DRAIN-WINDOWS` also verifies that egui reopened the GPUI-saved popout. Native live job cancellation and the remaining visual, pointer and mixed-DPI checks still need evidence. [Validation log](../VALIDATION_LOG.md)

## Routes and host

The `hash` plugin query emits `hash:open`, which dispatches `HashGeneratorCommand::Open` through the dialog host. File Search Calculate Hash and Downloads Triage supply a selected path. They must open in File mode with the original selected path. Reopening an active panel for the same path keeps its session, and supplying a different path invalidates the current calculation. See `src/plugins/hash_generator.rs`, `src/commands/handlers/hash_generator.rs`, `src/gui/command_host.rs`, `src/gui/mod.rs`, `src/gui/render.rs`, and `src/gui/downloads_triage_runtime.rs`.

`HashGeneratorWindowHost` uses utility key `hash-generator`. Docked and independent popout modes share a retained tool session. The popout has a 620 × 440 initial logical size, 420 × 320 minimum and scrolling. Host changes retain the draft and job. Close ends the session and invalidates the active request. The host owns its native file picker and Jump Mode targets, including the two dropdowns and their nested focus boundaries. See `src/gui/utility_window_host.rs` and `src/gui/hash_generator_dialog.rs`.

## Clipboard actions

Explicit Load and Copy use `ArboardClipboardBackend`. The read reaches the existing protected reader and its timeout policy. Accepted GPUI operations run outside the UI thread and `HashSession` lock, with one root-owned in-flight operation. `HashSession` owns shared snapshot, error and digest feedback. Load keeps a prior snapshot on failure and invalidates the earlier result only on a changed source. An empty string is a valid loaded snapshot. GPUI shows the byte count and current feedback.

Late Load checks mount, session, source generation and whether a rehost was accepted. An accepted Copy binds the current result and holds admission until the OS write and completion settle. Conflicting result changes, host moves, the native picker and close/restart are gated. Restart draft checks use opaque clipboard snapshot presence and revision. Clipboard contents remain transient data in the shared Hash session.
