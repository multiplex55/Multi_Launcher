# Add to Radial

G20 owns `radial-add-to-menu`. Launcher result Add to radial stages the eligible exact primary or secondary binding, or the typed current live query, for the [Radial Designer](radial-designer.md). The pending request owns source payload and destination consent. The authoring session owns accepted insertion.

| Criterion | Source-backed behavior |
| --- | --- |
| RADIAL-ADD-01 | Resolve the current real launcher activation semantic and stable assignment eligibility. Show unavailable reasons. Typed Save live query is distinct from stable action binding. Suppress the parent result activation. |
| RADIAL-ADD-02 | Wait for current authoritative draft and compatible modal state. Select stable menu/ring/cell, with occupied replacement and required CloseTree consent reset on destination change. Insert spacer, replace or append only after exact current validation. |
| RADIAL-ADD-03 | Apply one atomic draft edit, then select its exact destination. Cancel preserves the authoring draft. Persistence uses the separate Designer Apply/Save. |

Select `choosing_add_to_radial_suppresses_the_parent_result_activation`, `radial_add_primary_uses_launcher_resolution_and_keeps_secondary_choices_clear`, `pending_radial_add_waits_for_staged_properties_without_mutating_draft`, `changing_add_destination_cell_retires_replace_and_policy_consent` and `add_action_binding_uses_one_atomic_edit_for_spacer_append_and_replace`. Native and GPUI remain pending.
