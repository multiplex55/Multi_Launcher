# Downloads Triage

G11 owns `downloads-triage`. The built-in `downloads_triage` plugin accepts `downloads`, `downloads triage` and `downloads triage center` and emits the payload-free typed open action. `src/gui/downloads_triage_dialog.rs` owns the retained form and selection. `src/gui/downloads_triage_runtime.rs`, `src/downloads_triage` and the existing file transfer service own scan, exact admission, review data and file operations.

| Criterion | Source-backed behavior |
| --- | --- |
| DOWNLOADS-01 | Open one bounded Windows scan for the explicit profile root or Windows Downloads. Expose Choose root, Use Windows Downloads, Refresh and Set destination suggestion through their checked owner. Preserve root and suggestion in the versioned Downloads store. An unavailable explicit root reports its failure. |
| DOWNLOADS-02 | Present scan limits, failures, cancellation and separate skipped reasons. Search names by case-insensitive substring. Keep All/Unreviewed/Reviewed/incomplete/large/old installer/archive/same-size filters, grouping by type/age/size/origin, and name/modified/largest sort. Use bounded pages. Filter and sort do not broaden an exact checkbox selection. |
| DOWNLOADS-03 | Show accepted file times and sizes, reviewed state, class, same-size suspicion versus verified equality, and full or selected extraction provenance. Save reviewed actions against exact durable metadata. Compare accepts two eligible equal-size files and records verified byte equality locally. |
| DOWNLOADS-04 | Open, Reveal, Rename, Inspect and Extract require one exact current entry. Validate single-leaf Rename without overwrite. Copy/Move hands exact selected sources to File Operations Center for review and queueing. Inspect hands files to Hash and directories to Folder Size. Extract hands one eligible ZIP and suggestion to the ZIP utility. |
| DOWNLOADS-05 | Confirm Recycle Bin in the same viewport with bounded pages of exact armed paths. Confirm and Cancel have their own retained authority. Selection, scan or owner changes invalidate the decision. Dispatch through the existing Windows recycler and report confirmed/attempted/stopped/issues. |
| DOWNLOADS-06 | Preserve live dock/popout presentation and accepted-origin child delivery. Root-hidden operation remains observable. Close retires accepted selection, confirmation and active work. Replaced scans and windows reject late results. |

`G10-EGUI-ZIP-HANDOFF-PREVIEW` records the actual `downloads` route, isolated scan, exact item checkbox selection and ZIP handoff. Filters, files, Recycle Bin and most host criteria remain pending. Use `downloads_triage_dialog_session_retires_selection`, `downloads_triage_runtime_marks_exact_rows_and_rejects_a_stale_transfer_ticket`, `downloads_triage_review_is_durable_and_bound_to_the_exact_revision` and the affected scan/rename/compare tests. The actual native Recycle Bin fixture is ignored by default and belongs only in disposable acceptance. GPUI remains pending.
