# Data Recovery Confirmation

G06 owns `data-recovery-confirmation`. The Data and Recovery host opens a distinct confirmation for exact selected Restore or Reset. The data service owns accepted staging and next-start application.

| Criterion | Source-backed behavior |
| --- | --- |
| RECOVERY-CONFIRM-01 | Require current parent, confirmation, retained layer, eligible application-owned store or group and checked snapshot members. Confirm mints one typed private request. Cancel and close have no effect. Validate staging and next-start preservation independently. |

Select `confirmation_cancel_has_no_command_and_confirm_mints_one_typed_command`, `data_recovery_confirmation_jump_requires_retained_fresh_cancel` and `typed_recovery_request_is_staged_by_the_owned_worker`.
