# Radial Delete Impact

G20 owns `radial-delete-impact`, the Designer's read-only delete message for blocked authoring requests.

| Criterion | Source-backed behavior |
| --- | --- |
| RADIAL-DELETE-01 | Show the exact reason and available usage counts for the default or last menu, live references and ring errors. Bind the message to the current Designer child. A refused request leaves the draft intact. An eligible deletion applies as one undoable draft edit. |

Select `reference_impact_guards_delete_and_widget_ids_ignore_labels_and_indexes`. Native and GPUI remain pending.
