## Routes and ownership

`src/main.rs::spawn_gui` creates the egui root and binds it to the native invocation and foreground services. `gui/render.rs` owns the root query, result activation, dashboard admission and menu controls. `gui/search.rs` owns egui provider lifecycle and result state transitions. The scorer and ordered composition live in `src/actions/search.rs`. The GPUI shell reads the same custom actions and uses the shared installed-provider filter for Hash Search, then validates fresh activation before using its installed typed command route. The remaining result sources, navigation, context menus and Jump Mode still require implementation.

`launcher-result-context-menu`, `launcher-action-confirmation`, `universal-action-sheet`, `jump-mode-overlay`, `quick-help` and `command-help` are connected surfaces. G05 owns the route, payload, focus and dismissal contract for each. Utility targets, the Dashboard and authorship/settings destinations use the surface owners in [GUI inventory](../GUI_INVENTORY.md).
