# Radial Submenu Placement

G20 owns `radial-submenu-placement`. A current runtime fit/preparation failure publishes a correlated exact placement notice. The scoped native window owns Dismiss/Open Designer and the supported Cascade alternative. The existing runtime/store owns persisted policy recovery.

| Criterion | Source-backed behavior |
| --- | --- |
| RADIAL-PLACEMENT-01 | Show exact current failure context in the separate native window. Dismiss/OS close clear only the current notice. Open Designer focuses the authoring owner without exposing or repositioning a hidden launcher. |
| RADIAL-PLACEMENT-02 | SameCenter may offer Switch this parent to Cascade. Gate accepted request on current session, frame, menu and authoritative revision/digest. Success and failure update only the matching notice after correlated acknowledgement. |

Select `hidden_launcher_radial_notice_requests_one_stable_viewport_and_correlated_actions`, `placement_designer_action_opens_editor_without_showing_launcher`, `placement_dismiss_and_cascade_leave_hidden_launcher_unchanged`, `stale_placement_designer_action_cannot_show_launcher_or_change_panel` and `placement_alternative_preserves_session_and_frame_correlation_when_disabled`. Native and GPUI remain pending.
