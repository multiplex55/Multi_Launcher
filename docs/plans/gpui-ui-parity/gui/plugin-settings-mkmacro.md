| --- | --- |
| MKMACRO-SETTINGS-01 | Preserve the mouse and keyboard macros enable preference separately from whole-plugin enablement. The callback edits the draft. Accepted common settings reload applies provider availability and search routing. Opening/Cancel performs no playback or capture. |
