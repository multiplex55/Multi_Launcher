# Folder Alias

G06 owns `alias-editor`. Set Alias for a current folder result opens the retained Folder Alias form. A dropped folder follows a distinct storage path.

| Criterion | Source-backed behavior |
| --- | --- |
| FOLDER-ALIAS-01 | Preserve exact readonly path, current alias, blank clear, store validation and Cancel. Revalidate current known row and keep missing or malformed data protected. Verify stale prefill when the record is missing. |

Select `long_folder_target_scrolls_and_actions_stay_reachable_without_render_mutation` and the folder provider's `malformed_file_rejects_add_remove_and_alias_without_changing_bytes`.

Native and GPUI remain pending.
