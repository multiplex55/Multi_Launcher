# Dynamic Library Settings

G06 owns `plugin-settings-dynamic-library`. Common Settings can reveal a registered dynamic provider section keyed by exact name and library epoch. The enabled originating library remains pinned for its own provider handles.

| Criterion | Source-backed behavior |
| --- | --- |
| DYNAMIC-SETTINGS-01 | Preserve verified origin and epoch, unavailable and ambiguous entries, validated draft JSON and Save. Existing egui calls the provider's callback. Individual controls, effects and portable GPUI capability require provider-specific evidence. |

Select `settings_search_catalog_keeps_owner_identity_and_unavailable_prerequisites_truthful`, `settings_search_catalog_revision_tracks_registration_enablement_and_epoch_replacement` and `owned_handle_pins_only_its_originating_library`. No tracked DLL fixture exercises provider-defined controls.

Native and GPUI remain pending.
