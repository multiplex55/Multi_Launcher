# Programmer Inspector

G15 owns `programmer-inspector`. [Calculation Pad](calculation-pad.md) Tools → Programmer Inspector and a current eligible result → Inspect bits open the retained companion. The shared integer/inspector/comparison/bit-label code owns numeric and label semantics. The companion owns private edits, adopted result and current target.

| Criterion | Source-backed behavior |
| --- | --- |
| PROGRAMMER-01 | Adopt the current exact eligible Pad result without overwriting newer private draft edits. Preserve width, signedness conversion/reinterpretation, bases/formats, bit grouping/grid, ranges and labels. Keep local edits across allowed host changes and reopen. |
| PROGRAMMER-02 | Comparison binds the exact independently chosen input/Pad target. Clipboard and insertion are explicit current effects. Insert requires adopted candidate, current Pad UTF-8 caret and exact owner, then applies one session edit and returns editor focus. |
| PROGRAMMER-03 | Persist prefix, padding and grouping preferences with acknowledged write/retry. Label import/export uses the true native owner and versioned JSON containing labels. Different nonempty labels need [Replace bit labels?](programmer-inspector-label-replace.md). |
| PROGRAMMER-04 | Preserve accepted Pad receipt, document/incarnation and Inspector epoch/draft. Rehost keeps current work and rejects retired picker, comparison and edit results. |

Select `programmer_inspector_real_pad_selection_and_retained_bit_insert`, `programmer_inspector_stale_work_refresh_and_reopen_reject_old_caret`, `programmer_inspector_comparison_and_preferences_use_retained_host_receipts`, `inspector_label_file_import_export_is_labels_only_and_confirmed` and `inspector_label_file_stale_picker_and_confirmation_cannot_replace_new_work`.
