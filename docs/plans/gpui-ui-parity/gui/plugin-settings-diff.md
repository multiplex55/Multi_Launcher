G08 owns `plugin-settings-diff` in the common Settings host. Feature effects stay with the existing runtime owner.

| Criterion | Source-backed behavior |
| --- | --- |
| DIFF-PLUGIN-SETTINGS-01 | Preserve the callback's wrapping, highlighting, whitespace, case and pane split controls and its serialized configuration. The active Diff workspace loads its own persistence config. The callback's effect on that workspace is unconfirmed. |

Select `config_persistence_round_trip_keeps_table_preferences` and `settings_search_catalog_covers_builtin_and_dedicated_control_inventory` for separate type and Settings coverage.
