# Activity Center

G23 owns `activity-center`. Exact `activity` or File → Activity opens the root utility on current operation and terminal history snapshots. The operation owners retain cancellation and results.

| Criterion | Source-backed behavior |
| --- | --- |
| ACTIVITY-01 | Preserve visible throttled refresh, filter, current and terminal rows, resource summaries and Clear History. Copy explicit sanitized diagnostics through protected clipboard authority. |
| ACTIVITY-02 | Cancel only the exact current supported operation. Open Owner targets the accepted activity and live tool or retained transfer. Reject obsolete owners and jobs. |

Select `activity_prefix_routes_to_the_payload_free_typed_dialog`, `visible_refresh_is_throttled_and_closed_refresh_is_inert`, `activity_dialog_renders_open_filter_and_close_states`, `copied_text_contains_only_safe_owner_activity_metadata` and `file_operations_center_activity_requires_a_retained_exact_job`. Native and GPUI remain pending.
