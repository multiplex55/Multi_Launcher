# Macro Templates

G19 owns `mkmacro-templates`. [MkMacro](mkmacro.md) Reuse → New from Template opens the current stored template catalog. The existing template and import planner own the prepared independent copy.

| Criterion | Source-backed behavior |
| --- | --- |
| MK-TEMPLATES-01 | Show current catalog, selected description and Preview Copy. Preserve current exact selection/epoch and retained host. Preview and Cancel preserve document and template stores. |
| MK-TEMPLATES-02 | Create Independent Copy admits the exact reviewed template and current parent. Allocate new identities, clear copied hotkeys including dependencies, and apply through the same exact import transaction. |

Select `template_instances_are_fresh_independent_and_clear_every_hotkey`, `templates_survive_reload_and_capture_the_full_draft_closure`, `mkmacro_native_parent_opens_ordinary_children_with_retained_origin` and `package_children_keep_distinct_presentation_and_live_drafts`.
