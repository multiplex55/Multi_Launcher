# Delete Template?

G12 owns `note-template-delete`. The saved-row Delete action opens this separate focused decision inside the current [Note Templates](note-templates.md) host. It binds the staged exact name to the manager epoch and retained confirmation pass.

| Criterion | Source-backed behavior |
| --- | --- |
| NOTE-TEMPLATE-DELETE-01 | Show the specific pending template, disable conflicting manager actions and keep the decision's keyboard/Jump targets distinct. Jump focus alone has no effect. |
| NOTE-TEMPLATE-DELETE-02 | Cancel, Escape and title close clear the decision. Explicit Delete calls the current template owner, clears affected editor state and refreshes cache/search on success. Failure is visible and retains the decision. The current name and owner receipt govern admission. |

Select `note_templates_delete_cancel_works_with_jump_disabled`, `note_templates_native_delete_child_has_own_targets` and `note_templates_delete_hint_focuses_without_deleting`.
