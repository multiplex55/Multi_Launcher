# Blockers

Preparation has no unresolved blocker preventing delivery of these goals. Execution has not begun; unperformed Windows checks are pending work, not evidence of an inaccessible future environment.

When a real blocker occurs, record ID, goal/checkpoint/criteria, expected vs observed behavior, proof of cause vs hypotheses, attempts and new information, affected dependencies, safe independent work, smallest recovery action, required external capability/decision, partial-work location and linked AGENTS stall report.

Do not classify normal compiler errors or one failing migration test as a final blocker. Do not repeat identical attempts without new evidence. Preserve local commits after push failure and continue. Mandatory native checks stay unverified if the necessary Windows environment is unavailable.
