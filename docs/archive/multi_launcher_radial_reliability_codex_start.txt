NON-NEGOTIABLE BEHAVIOR
- Preserve the configured Shift+Alt+Win+End chord mapped to one key, with all keys released between gestures. Keep the configured hold threshold; 350 ms is only the absent-setting default.
- A short tap toggles the main grid on release, including while the main grid is focused. No outside click, pointer movement, extra hold-threshold wait, speculative key-down show, or debounce that drops rapid taps.
- IMPORTANT: short tap while the runtime radial is open BOTH toggles the main grid AND dismisses the runtime radial. This deliberately supersedes older tests/plans that kept it open. Dismissal must never execute a hovered cell.
- Holding opens/closes the runtime radial without changing the grid's existing visibility. A hold's release must not also generate a grid toggle. Retain existing sticky/release-to-select/hold-click semantics.
- Designer and native authoring preview are separate from runtime radial. Toggling the grid must preserve the Designer's window/session and unsaved draft. Retain exclusive capture/emergency priorities and all unrelated launcher functionality.
- A stale native restore or captured ROOT snapshot cannot undo a newer hide/show decision. Use the existing input/visibility owners, not competing hotkey handlers or a second state machine.

ACTION/QUERY GOAL
Create a shared query-first action editor for Cell Properties and Inspector. Rows show target title + action + type/disambiguator without requiring tooltips. Pinning preserves a supported target/action identity; Save query stores a live query. Auto Submit defaults OFF for new queries. ON resolves the same current first result as the main grid at activation time and dispatches it once through the existing action/command/safety boundary.

Do not silently skip an unavailable first result to run another target. No-result/unavailable Auto Submit opens the grid with the original query and explanation. Missing pins do not become queries. Non-UI actions do not flash/open the grid; required note editors/dialogs/confirmations/manual queries get their UI. Preview/search/assignment never execute or increment execution history/usage. Advanced exact commands reuse the existing parser/dispatcher and retain arguments; queries are not shell code. Keep dynamic result menus, contextual targets, alternate actions, and existing Quick Tools semantics.
