# Standalone synthetic reference

Standard-library Python only. This code reads the17 frozen research inputs, never production providers/settings/user data, and writes new receipts/results under evaluation/. No subprocess/network/application/native action, clipboard, parser invocation, dependency install or Rust code. P0 is a documented-policy lexical surrogate; no actual launcher relevance/latency claim.

Run from the repository root, once each under the published M2-A authorization:

```text
python -X utf8 -B docs/research/multi-launcher-research-20261028-r01/02-search-discovery/prototype/smoke.py
python -X utf8 -B docs/research/multi-launcher-research-20261028-r01/02-search-discovery/prototype/evaluate.py --candidate P0
python -X utf8 -B docs/research/multi-launcher-research-20261028-r01/02-search-discovery/prototype/evaluate.py --candidate P1
python -X utf8 -B docs/research/multi-launcher-research-20261028-r01/02-search-discovery/prototype/evaluate.py --candidate P2
```

The budget ledger refuses repeated initial attempts/overwriting output, reserves15s smoke/120s per candidate, enforces cooperative monotonic checkpoints and records cumulative actual guarded duration against600s. Interpreter startup and final receipt/ledger serialization are outside the measured guarded interval; the predeclared510s maximum leaves margin. Results are not a benchmark. A stopped/failed attempt remains recorded, including partial JSONL where available. No concurrent writers are supported/authorized.

Only one concrete correction cycle is permitted, with an explicit shared `--reason` and `--phase corrective`, affected `--candidate` IDs in one invocation≤120s and at most one corrective smoke≤15s. Preserve old outputs and document the defect in a separate deviation receipt before correction. Poor relevance is not a reason to rerun or tune. Original v1 inputs/manifest remain immutable; changed source/labels need versioned copies, never silent edits.

reference.py is pure: normalized fields, hard admission, fixture owner eligibility, integer score decomposition, final-token-only prefix, bounded one-edit evidence, role fractions/conflicts, exact action+args dedup, stable-ID ordering and threshold/chooser/abstention. All descriptors/scopes share the frozen gates and zero usage. Potential typo pairs require both lengths5–24 and absolute length difference≤1 (necessary for the frozen one-edit operations); **all** such otherwise-unmatched pairs are counted before choosing one correction per descriptor. Exceeding4096 abstains for the whole query. No wall-clock threshold changes scores or selects partial results.

evaluate.py processes both full15 and initial11 and all300 identical cases/labels in one candidate invocation, with complete per-case score explanations and per-split/family denominators. Replay, reversed descriptor enumeration and ignored count0/1,000,000 checks are within that invocation, not new candidates/evaluations. Frozen case labels are used only for measurement, never by rank/admission. Actual current provider/canonical outcomes are fixture inputs, not computed from Rust. Selection checks are final-state suppression fixtures, not a GUI state machine.

smoke.py checks a small fixed set of meaningful invariants/hand-worked arithmetic, not corpus relevance. Its synthetic zero-pair-cap fixture tests budget-wide rejection without changing frozen numerical files or introducing an evaluated policy. runtime_io.py verifies strict canonical UTF-8/LF hashes/lengths before each run, records sys.version/sys.platform/argv/code+input identities and preserves outputs. No platform helper spawns a subprocess.
